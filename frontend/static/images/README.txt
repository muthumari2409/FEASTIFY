FEASTIFY - your own images go in this folder
=============================================

Every picture on the website first looks for a file here. If the file is
missing, it automatically falls back to a free online photo (Unsplash), and if
that also fails, a branded placeholder is shown. So the site never shows a
broken image.

To use your own photo, save it here with EXACTLY one of these names (.jpg):

  hero.jpg         - big home page background
  restaurant.jpg   - restaurant interior (home "our story" section)
  about.jpg        - about page
  chef.jpg         - head chef (about page)
  chef1.jpg chef2.jpg chef3.jpg - team members (about page)
  food1.jpg food2.jpg food3.jpg - featured dishes (home page)
  gallery1.jpg ... gallery12.jpg - gallery page photos
  guest1.jpg guest2.jpg guest3.jpg - testimonial faces
  login.jpg        - side picture on the login page
  register.jpg     - side picture on the register page

Tips: landscape photos about 1600px wide for hero.jpg, around 1000px for the
rest. Press CTRL+F5 in the browser after adding a file.

Note: while a file is missing you will see a harmless "404" line for it in
the terminal/browser console - that is just the fallback working.
